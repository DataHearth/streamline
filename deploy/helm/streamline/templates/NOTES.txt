First-boot admin: seed_admin is applied ONCE, against an empty DB on first
boot — setting or changing it later is ignored (the existing admin keeps its
password; a lost one is reset with `streamline auth set-password`, not by
re-seeding). Unless you set
config.auth.seed_admin, a default admin (admin@streamline.local) is created
with a random password printed once to the pod's stdout — on every deploy, not
just read-only ones; it is never written back to the config:
  kubectl --namespace {{ .Release.Namespace }} logs deploy/{{ include "streamline.fullname" . }} | grep -i "default admin"
Anything scraping container stdout captured it too, so change it from your
account page after your first login.
